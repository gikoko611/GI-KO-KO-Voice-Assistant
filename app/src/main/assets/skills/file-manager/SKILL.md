# File Manager Skill

Android Storage Access Framework (SAF) ကို အသုံးပြု၍ user ရွေးချယ်ပေးသော document များကိုသာ ဖတ်/ရေးပါ။

- PDF, TXT, JSON နှင့် source code များကို user ရွေးချယ်ပြီးမှသာ ဖွင့်ပါ။
- Export မလုပ်မီ destination ကို user ရွေးချယ်ခွင့်ပေးပါ။
- အခြား app ၏ private data၊ protected folder သို့မဟုတ် permission မရထားသော path များကို မဝင်ရောက်ပါနှင့်။
- File ဖျက်ခြင်း/အစားထိုးခြင်းကို သီးခြား confirmation မရှိဘဲ မလုပ်ပါနှင့်။
