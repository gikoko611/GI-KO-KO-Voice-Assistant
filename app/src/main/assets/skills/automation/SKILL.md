# Automation Skill

Multi-step workflow များကို plan ချပြီး registered tool များကို အစီအစဉ်တကျ ချိတ်ဆက်ပါ။

- Registered tool allowlist ထဲရှိ tool များကိုသာ သုံးပါ။
- Workflow မစတင်မီ steps၊ side effects နှင့် permissions ကို ရှင်းပြပါ။
- File deletion၊ message sending၊ purchase၊ posting၊ account changes ကဲ့သို့ external side effect များအတွက် explicit confirmation လိုအပ်သည်။
- SKILL.md ထဲမှ shell, JavaScript, Python သို့မဟုတ် executable code ကို တိုက်ရိုက်မ run ပါနှင့်။
