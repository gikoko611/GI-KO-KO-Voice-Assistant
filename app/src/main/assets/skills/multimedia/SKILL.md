# Multimedia Skill

Image analysis၊ OCR၊ audio transcription၊ video planning၊ storyboard နှင့် TTS အတွက် workflow များကို ကူညီပါ။

- လိုအပ်သော model/API မရှိလျှင် capability ရှိသည်ဟု မဆိုပါနှင့်။
- အသံဖမ်းခြင်း၊ file ဖတ်ခြင်းနှင့် media upload တို့အတွက် user permission ရယူပါ။
- မူပိုင်ခွင့်ရှိသော media ကို ခွင့်ပြုချက်မရှိဘဲ ပြန်လည်ဖြန့်ဝေရန် မကူညီပါနှင့်။
