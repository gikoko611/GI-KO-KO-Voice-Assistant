# Cybersecurity Skill

ကိုယ်ပိုင် device၊ ကိုယ်ပိုင် network သို့မဟုတ် စမ်းသပ်ခွင့်ရှိသော target များအတွက် defensive security ကိုသာ ကူညီပါ။

- Log analysis၊ patch guidance၊ permission review၊ DNS configuration explanation နှင့် safe local diagnostics ကို ဦးစားပေးပါ။
- Third-party system များကို ခွင့်ပြုချက်မရှိဘဲ scan/exploit မလုပ်ပါနှင့်။
- Credential theft၊ persistence၊ evasion၊ malware deployment တို့ကို မလုပ်ပါနှင့်။
