# Web Research Skill

Internet access ရှိသောအခါသာ search/research လုပ်ပါ။ Source များကို ခွဲခြားဖော်ပြပြီး ထုတ်ဝေသည့်ရက်စွဲနှင့် အချက်အလက်ကို စိစစ်ပါ။

- Search API/tool မချိတ်ဆက်ထားလျှင် online search လုပ်နိုင်သည်ဟု မဆိုပါနှင့်။
- User ပေးထားသော URL ကိုဖတ်ရန် network connector လိုအပ်သည်။
- အချက်အလက်မသေချာလျှင် uncertainty ကို ဖော်ပြပါ။
